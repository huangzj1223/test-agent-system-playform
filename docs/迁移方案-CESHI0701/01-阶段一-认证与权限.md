# 阶段一：用户认证与权限 RBAC（P0-3）实施记录

> 参考蓝本：CESHI0701 `server/src/modules/base`（auth/user/role/menu/department/position）
> 实现框架：当前项目 FastAPI + SQLAlchemy + Alembic + PostgreSQL + Redis（不引入新框架）

## 目标功能

- 用户名+密码登录（bcrypt 校验）
- JWT 双 Token（access + refresh），Redis 缓存 token 与权限，改密后旧 token 失效（password_v）
- 用户 / 角色 / 菜单 / 部门 / 岗位 管理（CRUD）
- 角色-菜单绑定 → 权限标识（perms）门控
- 受保护 API：无有效 token 返回 401；无权限返回 403
- 前端：登录页 + 后台管理页（Next.js + shadcn/ui，不引入 Vue）

## 验收方式

启动方式（本地无 Redis 时）：
- 后端：`cd backend` 后设 `REDIS_USE_MEMORY=true`、`AUTH_DEV_SECRET=<任意>`，
  用 venv 的 python 跑 `python -m uvicorn app.main:app --port 8001`
- 前端：`cd ui && npm run dev`（:3000，已配置 /api 代理到 :8001）
- 浏览器访问 http://localhost:3000/login ，用 admin / 123456 登录，
  登录后访问 /admin/users 管理用户。

## 验收标准

1. `POST /api/v2/auth/login` 用 admin/123456 登录成功，返回 access/refresh token。
2. 带 token 访问受保护接口成功；不带 token 返回 401。
3. `POST /api/v2/auth/refresh` 能刷新 token。
4. 能新增角色并绑定菜单，普通用户按 perms 受控。
5. 前端登录页可登录、token 持久化、401 自动跳登录。
