## 对话能力边界

1. 普通问答调用已配置模型，浏览器只接收服务商 ID 和模型 ID，不接收密钥或服务地址。
2. 对话只可路由到登记在桥接白名单中的测试智能体，不提供任意 Python、Shell 或桌面程序入口。
3. Web 浏览器任务默认为 L2，必须由当前用户批准后执行；删除、覆盖等写操作提升为 L3。
4. 生产数据删除、格式化磁盘、数据库清空等 L4 指令直接阻断，不进入执行器。
5. 智能体上下文只允许项目标识、目标 URL、测试运行 ID、文件夹 ID等受控字段，并限制长度。
6. AgentRun 持久化状态、风险、批准人、结果、错误和证据路径；跨用户查询被隔离。

## 暂缓与不适用

| 项目 | 状态 | 原因 |
|---|---|---|
| 角色、菜单、部门管理前端扩展 | 暂缓 | 用户明确要求本轮不做；既有后端不删除 |
| Chrome 扩展接管用户现有会话 | 暂缓 | 当前测试平台已有隔离 Playwright 会话，扩展会扩大权限与会话泄露风险 |
| 任意 Windows 桌面程序控制 | 不适用 | 超出测试智能体治理边界，难以可靠审批、回放和审计 |
| Vue/NestJS 原代码迁入 | 不适用 | 与当前 FastAPI/Next.js 架构不一致，已按现有技术栈重写 |

## 最终验收要求

最终结论必须以当次 fresh run 为准，至少包含：

- Alembic 升级到 `0016_agent_runs` 且 `current` 为 head；
- 后端阶段专项、治理、审批、浏览器桥接测试；
- 前端 TypeScript 与生产构建；
- 后端和前端服务启动后的登录、对话、模型选择、审批和历史恢复；
- 浏览器控制台无本次新增 error，关键 API 无失败请求；
- 服务与浏览器测试会话在验证结束后关闭。
