# 协作棱镜全系统图标设计说明

## 1. 目标

建立一套与智能体测试系统定位一致的完整图标语言，替换现有黑金品牌图标，并统一品牌、导航、业务类型、状态和操作图标的造型、颜色与使用规则。

## 2. 品牌标识

品牌标识采用“协作棱镜”：

- 六边形外框代表质量边界和稳定系统。
- 中央节点代表质量中枢。
- 三个外围节点代表测试智能体之间的协作。
- 中心与外围连线代表需求、设计、执行、分析、修复和验证的数据流。
- 靛蓝为主色，青色表示运行，荧光绿表示闭环完成，琥珀色表示待确认。

品牌标识提供以下变体：

- 深色导航使用亮色描边版本。
- 浅色页面使用深靛蓝描边版本。
- 浏览器标签使用简化的小尺寸版本。
- 单色环境使用当前文字颜色，不依赖渐变和阴影。

## 3. 图标层级

### 3.1 品牌层

用于侧栏产品名称、浏览器标签、登录页、加载页和系统级空状态。品牌标识不用于普通按钮或业务操作。

### 3.2 导航层

导航图标保持统一的 1.8 像素线宽，并按业务语义重新映射：

| 功能 | 图标语义 |
| --- | --- |
| 系统总览 | 质量轨道 |
| 智能体任务 | 智能网络 |
| 项目空间 | 模块集合 |
| 项目洞察 | 风险雷达 |
| 测试用例 | 校验清单 |
| API 测试 | 接口代码 |
| Web 测试 | 浏览器面板 |
| 渗透测试 | 安全校验 |
| 测试运行 | 播放与执行 |
| 测试计划 | 时间计划 |
| 测试报告 | 趋势报告 |
| 全栈分析 | 扫描分析 |

导航默认仅显示线性图标；激活状态使用浅色方形底板和对应强调色，不为每个导航项使用不同颜色。

### 3.3 业务类型层

测试用例、API、Web、渗透、运行、报告和智能体任务使用独立但统一的业务图标。首页快捷入口和业务页标题复用同一个图标映射，不允许同一业务在不同页面使用不同符号。

### 3.4 状态层

状态图标与颜色建立固定映射：

| 状态 | 图标 | 颜色 |
| --- | --- | --- |
| 运行中 | 旋转进度环 | 青色 |
| 已就绪 | 实心状态点 | 靛蓝 |
| 已完成 | 圆形校验 | 荧光绿 |
| 需关注 | 三角提醒 | 琥珀色 |
| 已阻塞 | 八边形错误 | 珊瑚红 |
| 空闲 | 虚线圆环 | 中性灰 |
| 待接入 | 断开连接 | 中性灰 |

状态不能只依赖颜色，同时显示图标和中文文本。

### 3.5 操作层

新增、刷新、编辑、删除、导出、筛选、展开、跳转、关闭等操作继续使用用户熟悉的线性符号。图标按钮必须提供 `aria-label` 和悬停说明，按钮尺寸不小于 36 像素。

## 4. 组件与文件结构

- `ui/components/brand/system-mark.tsx`：品牌 SVG 组件和深浅色变体。
- `ui/components/icons/product-icons.tsx`：全局导航和业务图标映射。
- `ui/components/icons/icon-frame.tsx`：导航、业务和状态图标容器。
- `ui/components/icons/status-icon.tsx`：状态名称、图标和颜色的统一映射。
- `ui/public/brand-mark.svg`：静态品牌标识。
- `ui/public/icon.svg`：浏览器标签小尺寸标识。

页面不得再次直接引用旧的 `/logo.svg` 和 `/avatar.png`。

## 5. 全局替换范围

本次统一替换：

1. 左侧导航产品 Logo。
2. 浏览器标签图标和页面元数据。
3. 顶部用户区域的旧图片。
4. 全局导航和项目导航图标。
5. 首页指标、智能体星图、快捷入口、项目战情、个人处置台、闭环效率和活动流图标。
6. 通用状态图标样式和 Lucide 全局线宽。
7. 页面标题、按钮和弹窗中显眼的业务图标按照新映射逐步统一。

保留 Lucide 作为基础图标库，不批量绘制 83 份重复 SVG。产品语义通过中央映射和统一容器实现，确保后续新增页面自动遵循同一体系。

## 6. 视觉规则

- 品牌标识默认尺寸为 36 像素，紧凑位置为 24 像素，浏览器图标为 32 像素画布。
- 普通导航图标为 16 像素，业务入口图标为 18 至 20 像素。
- 线宽统一为 1.8 像素，端点和连接处使用圆角。
- 图标容器圆角为 6 至 8 像素。
- 同一行图标必须使用相同视觉尺寸和对齐方式。
- 不使用 Emoji 作为状态或业务图标。
- 不使用多色渐变填充普通功能图标。

## 7. 验收标准

- 系统中不再显示旧黑金 Logo 和旧头像图片。
- 侧栏、浏览器标签、首页和主要业务入口使用统一品牌与业务图标。
- 同一业务在所有高频入口中使用同一符号。
- 状态同时通过中文、图标和颜色表达。
- 桌面、平板和移动端图标不变形、不模糊、不挤压文字。
- TypeScript 检查通过，浏览器控制台无错误。
- 通过桌面和移动端截图检查图标的识别度、对齐和配色协调性。
