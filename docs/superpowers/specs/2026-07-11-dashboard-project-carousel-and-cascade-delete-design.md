# 首页项目星图轮播与级联删除设计

## 目标

完善系统首页的项目管理和智能体协作星图，使项目创建、展示、分析和删除形成一致的数据闭环。

本次范围包括：

- 首页只保留一个“新建项目”入口。
- 项目创建、编辑和删除后，首页与左侧项目菜单立即同步。
- 智能体协作星图支持“全量视图 + 单项目视图”的双层自动轮播。
- 星图阶段按业务顺序自动高亮，下方分析与当前阶段同步。
- 删除项目时展示完整影响范围，确认后删除数据库记录及对象存储成果物。

## 首页项目操作

### 新建入口

只保留首页标题操作区右上角的“新建项目”按钮。全局项目战情区域不再显示重复入口。

### 数据同步

项目创建、编辑和删除成功后，页面依次刷新：

1. `ProjectContext` 中的项目列表，用于更新左侧项目菜单。
2. 首页仪表盘数据，用于更新指标、项目战情和星图轮播。

刷新过程中保留当前页面，不执行整页重载。创建成功后，新项目进入左侧菜单及星图轮播序列。

## 智能体协作星图

### 视图序列

星图包含一个全量视图和若干项目视图，顺序固定为：

`全部项目 -> 项目 1 -> 项目 2 -> ... -> 全部项目`

初次进入首页时默认显示全部项目。项目顺序沿用仪表盘接口返回顺序。

### 阶段序列

每张星图包含七个阶段：

1. 需求解析
2. 测试设计
3. 脚本生成
4. 自动执行
5. 结果分析
6. 失败修复
7. 回归验证

当前视图从需求解析开始，按顺序自动高亮阶段。阶段全部播放完毕后，切换到下一张星图，并重新从需求解析开始。

### 节奏与交互

- 每个阶段停留 3 秒。
- 七个阶段完成后切换下一张星图。
- 环形连线增加清晰的方向箭头，表达闭环流向。
- 中心节点显示“全部项目”或当前项目名称。
- 顶部显示当前视图位置，例如“全部项目 · 1/4”或“数据工厂 · 2/4”。
- 提供上一张、暂停/继续、下一张控制。
- 点击分页指示器可直接切换视图。
- 点击阶段后立即更新下方分析，并暂停自动播放 8 秒，随后恢复。
- 点击项目控制、鼠标悬停星图时暂停播放；离开后恢复。
- 浏览器标签页不可见时停止计时，重新可见后继续，避免后台累计跳转。

### 分析卡联动

下方分析卡始终对应当前高亮阶段，展示：

- 当前视图名称。
- 阶段名称、状态和数量。
- 阶段说明与异常数量。
- 对应项目业务页面的跳转入口。

全量视图使用后端返回的系统汇总阶段；项目视图使用该项目的测试用例、脚本、运行、失败、阻塞和通过数据生成阶段状态。

### 响应式

桌面端保留环形星图。移动端使用阶段列表，但沿用相同的视图和阶段轮播状态，当前阶段具有明确高亮，下方分析同步更新。

## 项目级联删除

### 删除影响预览

新增删除影响查询接口，删除确认框打开时加载并展示当前项目关联数据统计，包括：

- 文件夹、测试用例及步骤。
- API 接口、API 测试及脚本。
- Web 页面、功能、测试及脚本。
- 场景测试、步骤和运行结果。
- 测试计划、测试运行及任务。
- 失败分析、自动修复闭环和测试报告。
- 渗透测试、漏洞和报告。
- 附件及 MinIO 成果物。

确认框明确提示删除不可恢复，并要求输入项目名称后才启用“永久删除”按钮。

### 后端删除服务

删除操作由专用服务统一处理：

1. 验证确认项目标识与目标项目一致。
2. 查询并保存所有关联 MinIO 对象名称及其他成果物路径。
3. 删除对象存储中的项目成果物；若对象存储删除失败，则中止数据库删除并返回明确错误。
4. 在数据库事务中删除项目，依赖外键级联删除项目关联记录。
5. 提交事务并返回删除统计。

数据库迁移和模型检查需确保所有直接项目关联表均使用 `ON DELETE CASCADE`，不允许因遗漏外键留下孤立数据。

### 删除后的前端状态

删除成功后关闭确认框，同时刷新项目上下文和首页仪表盘。若删除的是当前选中项目，左侧菜单切换到剩余项目中的第一项；没有剩余项目时显示空状态。

删除失败时保留确认框和影响统计，显示后端返回的具体失败原因，不提前从界面移除项目。

## 组件边界

- `ProjectsPage`：项目弹窗、数据刷新编排和唯一新增入口。
- `AgentConstellation`：视图与阶段双层轮播、交互暂停和分析联动。
- 轮播模型模块：纯函数生成视图序列、项目阶段和下一状态，便于单元测试。
- `ProjectDeleteDialog`：加载删除影响、名称确认和删除提交。
- `ProjectService`：删除影响统计、对象路径收集和级联删除。

## 测试与验收

### 前端自动测试

- 默认视图为全部项目。
- 视图序列包含全部项目和所有项目。
- 七个阶段播放完后切换下一视图。
- 手动选择阶段时分析内容同步。
- 创建项目成功后同时调用项目列表与仪表盘刷新。
- 删除确认名称不匹配时按钮不可用。

### 后端自动测试

- 删除影响统计覆盖主要项目资源。
- 确认标识不匹配时拒绝删除。
- 项目删除后关联数据库记录不存在。
- MinIO 删除失败时项目数据库记录保持存在。
- 删除成功时返回数据库和成果物删除统计。

### 浏览器验收

- 首页只存在一个“新建项目”入口。
- 新建项目后左侧菜单无需刷新页面即可出现新项目。
- 全量星图和项目星图依次自动轮播。
- 环形箭头清晰，当前阶段与下方分析一致。
- 删除弹窗完整显示影响范围并要求输入项目名称。
- 桌面端和移动端无横向溢出、文字遮挡或控制跳动。
