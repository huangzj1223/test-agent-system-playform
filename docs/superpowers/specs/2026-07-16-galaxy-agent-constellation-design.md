# 智能体协作星图银河闭环设计

## 目标

在不改变首页整体栅格、右侧质量简报以及 `DashboardAgentStage` / `DashboardProjectSituation` 数据结构的前提下，将固定 SVG 星图升级为可运行的七阶段银河闭环。中心项目固定，外围节点按业务顺序形成闭环，并提供连续空间运动、阶段详情同步、项目视图切换和无动画降级。

## 技术边界

- 沿用 Next.js 14、React 18、TypeScript、Tailwind CSS、SVG 和 Lucide 图标。
- 不新增生产依赖，不修改后端接口、数据库或首页栅格。
- 修改限定在星图组件、Canvas 粒子层、星图纯函数模型、专用样式和测试。
- 首页当前已有用户修改；实现不覆盖 `ui/app/projects/page.tsx`。

## 架构

`AgentConstellation` 继续接收原有 `stages` 与 `projects` 属性，并继续使用 `buildConstellationViews` 和 `buildAgentStageView`。新增纯函数负责阶段顺序、带停留的缓动相位、椭圆坐标、深度表现和 SVG 轨道弧线；React 组件只管理播放、页面可见性、悬停、视图切换和点击聚焦状态。

星空由独立 `GalaxyParticleLayer` Canvas 组件绘制。粒子按容器尺寸和设备像素比生成，使用 `ResizeObserver` 更新画布；暂停、页面隐藏或 `prefers-reduced-motion` 时停止位移，卸载时释放动画帧和观察器。

## 视觉与运动

- 星图内部严格参照两张原型：深蓝、靛蓝和紫色背景上必须有覆盖主视觉上下区域的中央暖色亮核、三条以上冷色旋涡星臂、穿插其中的暗尘埃带、高密度蓝紫星团、少量橙色恒星和贯穿底部的银河云带，不能只显示纯深色底和少量随机星点。
- 主银河外围分布六个大小、扁率、倾角和色相不同的伴星系，形成近景主银河、远景星系与深空星点的三层空间关系；伴星系保持低亮度，不抢夺业务节点焦点。
- 中心“全部项目/当前项目”使用后景能量光晕、倾斜吸积盘、双层轨道、球形暗部和前景高光透镜形成可辨识的前后层次，而不是平面圆形标签。
- 七个节点使用半透明深色玻璃和阶段专属颜色，不再使用白色矩形卡片。
- 每个阶段约 2.3 秒，前 42% 保持焦点，之后通过正弦缓动移动到下一阶段；一圈约 16.1 秒。
- 3D 模式将相位映射为 `translate3d`、`scale`、`opacity`、`blur`、`brightness` 和 `z-index`。最近阶段约 1.22 倍，最远阶段约 0.5 倍。
- 2D 模式保留环形运动和业务顺序，但取消模糊并压缩缩放差，便于阅读。
- 节点坐标的角度必须随相位递增，在浏览器 Y 轴向下的坐标系中形成可验证的顺时针运动。
- 主流程箭头严格沿顺时针椭圆切线连接相邻阶段，使用蓝白高亮光束、柔和彗尾和清晰箭头头部；不可表现为低亮度彩色虚线圆环，也不可指向中心。
- 当前阶段到下一阶段的箭头叠加阶段色高光；装饰轨道和星尘使用不同速度，中心能量环独立缓慢旋转。

## 交互与数据流

- 悬停星图暂停自动相位；悬停节点临时展示该节点详情。
- 点击阶段后按顺时针方向平滑聚焦，并暂停自动播放 5 秒。
- 播放/暂停和 2D/3D 控件始终可见；项目超过一个时保留前后项目切换。
- 点击中心：项目视图进入 `/projects/{identifier}`，全量视图进入 `/projects/spaces`。
- 详情区直接展示现有状态、任务数、异常数和说明；数据模型没有负责人或预计完成时间时明确显示“待数据接入”，不伪造业务数据。
- 每完成七阶段循环后进入下一项目视图，并从阶段 01 继续，保留原有全量/项目轮播语义。

## 可访问性与降级

- 阶段节点使用原生按钮，支持键盘焦点和可读标签；控制按钮提供中文 `aria-label`。
- `prefers-reduced-motion` 下停用 RAF 自动巡航，显示静态环形流程；用户仍可点击阶段和切换项目。
- 页面隐藏时暂停动画，恢复后从原相位继续。
- 移动端继续使用简化阶段列表，不改变七阶段顺序。

## 验证

- Node 测试覆盖阶段顺序、缓动停留、焦点计算、3D 深度、2D 降级、实际顺时针坐标变化、椭圆箭头路径、旋涡星尘和外围伴星系种子分布。
- TypeScript 检查和 Next.js 构建验证类型与生产编译。
- Playwright 在 1440×900 和 1920×1080 检查页面加载、控件、阶段点击、详情同步、控制台、关键请求、重叠和截图效果；截图必须可见底部银河云带、七段蓝白箭头及节点顺时针位移。
